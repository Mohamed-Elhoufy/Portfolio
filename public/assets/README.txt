PROFILE PHOTO
=============
Put your photo in this folder and name it exactly:

    profile.jpg

Recommended: a portrait, roughly 4:5 ratio (e.g. 800 x 1000 px), under 300 KB.
Until the file exists, the website shows a clean placeholder instead.

Using a different file name or format (png/webp)? Change `photo` in src/data/portfolio.js.
